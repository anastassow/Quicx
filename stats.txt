Subsystem  Variable          Struct      C type    Kind      Cardinality     Tells you
---------  ----------------  ----------  --------  --------  --------------  ---------

           tasks_completed   Stats       uint64_t  counter   per shard       total finished OK

           total_blocks      SizeClass   uint32_t  constant  per class (×N)  blocks carved at split — denominator for allocated_blocks
           block_size        SizeClass   size_t    constant  per class (×N)  payload bytes per block in this class
           size              MemoryPool  size_t    constant  per pool        usable capacity — denominator for used
           num_size_classes  PMAD        uint8_t   constant  per shard       how many classes exist
           pool_size         PMAD        size_t    constant  per shard       bytes originally requested from the OS
